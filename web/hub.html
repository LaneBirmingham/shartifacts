Public links

      

        Anyone with a link can use this app, frontend and backend, without reaching the rest of
        shartifacts. Revoke a link to end it at once.
      

      

        Public links are off, so this server runs in private mode. To turn them on, set
        SHARTIFACTS_SHARE_ORIGIN to a hostname of yours and route it to port 8081;
        docs/sharing.md
        has the steps, or ask your agent.
